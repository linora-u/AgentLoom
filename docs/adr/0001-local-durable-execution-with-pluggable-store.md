# 持久执行默认本地运行，存储后端可替换

AgentLoom 的持久任务执行默认使用本地持久状态，并通过可替换的存储接口支持未来远程后端。这保持现有本机 CLI 的使用方式，也允许后续扩展部署范围；当前采用 DBOS 3.2.0 的默认 SQLite。2026-10-14 按用户要求停止扩展自研内核，采用成熟开源引擎，具体接入见 [当前规格](../specs/durable-worker-open-source-engine-integration-v2.md)。远程替换使用上游公开连接配置或执行接口，不通过私有表继续驱动另一套领取循环。

首版覆盖单机多进程，共享阶段容量。旧 Worker 先停止并确认本机资源退出，再恢复补位；远程存储接口不等于首版已支持多机器分布式执行。当前产品使用 DBOS 3.2.0 官方队列和默认 SQLite，以及 macOS launchd 管理一次完整 Application。框架不新增任务租约或续约；取消 ACK、数据库终态和引擎 destroy 返回均不能证明旧工作已退出。

业务账本和执行状态分库。业务权限检查、最终结果与完成回执在业务库的同一事务提交；恢复通过稳定任务身份与回执协调，不承诺跨库原子提交。未来远程后端同样需要明确幂等、提交确认与恢复协议。
