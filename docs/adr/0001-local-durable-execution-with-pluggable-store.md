# 持久执行默认本地运行，存储后端可替换

AgentLoom 的持久任务执行默认使用本地持久状态，并通过可替换的存储接口支持未来远程后端。这保持现有本机 CLI 的使用方式，也允许后续扩展部署范围；SQLite 为首选本地候选。2026-10-14 按用户要求停止扩展自研内核，优先验证成熟开源引擎，具体接入见 [当前规格](../specs/durable-worker-open-source-engine-integration-v2.md)。远程替换使用上游公开连接配置或执行接口，不通过私有表继续驱动另一套领取循环。

首版覆盖单机多进程，共享阶段容量。失去租约的旧 Worker 先停止并确认本机资源退出，再恢复补位；远程存储接口不等于首版已支持多机器分布式执行。该边界优先保证本地资源收尾和任务恢复一致，避免仅因数据库租约过期就重复启动仍在运行的工作。

业务账本与任务状态能否原子提交取决于后端，不能把同一 SQLite connection 的事务能力承诺为所有远程实现的公共合同。远程后端需要明确幂等、提交确认与恢复协调协议。
