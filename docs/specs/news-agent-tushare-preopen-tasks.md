# 新闻下载与盘前分析开发任务

对应 [开发规格](news-agent-tushare-preopen-spec.md)。

- [x] 独立自然日、起止日期范围下载，保存收盘前内容和休市日内容。
- [x] 按来源维护覆盖进度，补齐前一交易日起的缺口及当天新增数据。
- [x] 网络与 PDF 共用最多六次请求、三秒等待及 Retry-After 策略。
- [x] 保留脱敏后的完整错误、调用栈和重试历史；部分失败保留成功数据。
- [x] 汇总多份下载回执，按分析窗口计算覆盖及缺口。
- [x] 准备输入立即固定，追加下载不改变原运行，更换设置使用新目录。
- [x] 复用初筛、精筛、校验、冲突校验及日期归属，组合入口继续分析可用输入。
- [x] 完成回执、共享目录使用锁及独占清理；预览与实际清理分开。
- [x] 清理保留活动、未完成及未识别运行，保护原始库和行情目录。
- [x] 保留环境变量优先、本地配置兜底，忽略不可用旧采集回执。
- [x] 真实单日下载、增量及盘前准备验证，真实 PDF 正文下载和提取验证。
- [ ] 全量新闻回归、框架相关回归、静态检查及提交前复核。
