# news_agent 当前约定

完整读取新闻快讯、长篇新闻、新闻联播文字稿、国家政策库、央行货币政策报告。正文完整分段并保持来源、原记录和字符区间。初筛仅做一次全量分类，每条新闻都有入选或剔除状态；入选完整原文交精筛。

精筛是最终决策阶段。Agent 使用 Skill，自主理解和核实首披、事实增量、执行状态、事前认知、ETF 净暴露及开盘后余效；行业 reference 按需读取。来源与历史版本不明时放弃并说明疑点。程序记录结果、运行失败和用量，不用工具动作或 URL 日志判定业务审核成功。

精筛模型只输出 reviews，每项含 event_id、etf_code、record_numbers、summary、decision、reason、sources。全部候选序号必须有审核记录。程序精确还原原 ID，推荐项使用候选 ETF 代码，利好/利空从 reviews 提取；没有另一份模型 events 输出，也没有固定放弃原因枚举。

同一入场日同一 ETF 的精筛结论按利空优先直接合并：有利空即利空，没有利空时保留利好，全部放弃则没有交易信号。全部原始判断和放弃保留。精筛之后不调用来源复核、事件合并、净方向或新事件计数 Agent。

历史回放仅采用新闻日 23:59:59+08:00 前可核实已公开的材料。Agent 自行确认原始发布和当时版本，不采用未来行情、后来进展或后修正文。证据保存 URL、公开时间、版本可得时间和短摘；这些是 Agent 核实记录。

正式名单在读取收益前固定，以入场交易日×ETF 为一笔；不同 ETF 的有效判断分别计数，不再分组选代表。正式数量与主命中率使用同一名单，全部原始映射另报。相关 ETF 信号存在相关性，不能视为统计上相互独立的证据。报告已记录事件数，不将跨批次未经语义去重的数量称为独立新事件数。

收益为下一有效交易日 T0 复权开盘至 T+3 复权开盘，经过三个完整交易日。利好 R≥+2%，利空 R≤−1.5%，均含等号。开盘前跳空不计收益；日内反转只作诊断，利空用于风险预警。失败、迟到、缺价和未完成样本保留在分母并如实报告。

阶段数量及胜率目标由当前 Goal 表达，程序不写死最低数量、最低入场日或目标胜率，也不自动判断业务通过或失败。程序记录逐日、逐月和两类信号的客观统计，区分无信号日期、预测缺失和计分未完成；后续按已配置月份运行，结果交给主 Agent 审核。主 Agent 分析漏选、过度拒绝、事实核实、ETF 映射及正常预测误差，确认规则缺陷后再优化 Prompt 或 Skill，不为了数量补造信号或缩减新闻。

先完成完整开发月预测和正式名单再读取收益。用于修改规则的月份不能充当独立验收。保留输入、错例、原始响应和用量记录，直接修改当前代码，不保存旧代码版本或兼容分支。冻结后方法改变则重新建立验收计划。

config/settings.yaml 管理应用预算、并发、日历及计分；config/model.yaml 管理模型、推理和重试。本次不改变模型或 xhigh。初筛和精筛分别使用本阶段缓存；全局方法指纹用于正式验收，不作为全部初筛缓存的依赖。只有运行和输入输出完整性问题需要程序纠正或失败重试，业务疑点由 Agent 判断或弃权。

先交付完整开发月，再扩至连续两月、三月与全年。代码或相关测试通过只证明实现检查，不证明新闻预测达标。
