# 固态电池产业链的商业化层级

本 reference 提供技术和传导判断方法。历史回放采用证据截止前可核实的新闻与原始发布，材料中的旧案例不能替代当日事实；审核结果按精筛 Prompt 的格式保存。

1. 先区分半固态、全固态与未确认口径：液态电解液、传统隔膜、电解质路线、负极路线，以及参数是材料、单层电芯、多层电芯、电池包还是整车数据。术语“固态”本身不证明全固态或量产。
2. 按可验证里程碑提升判断：单层实验 → 多层/大容量 → A/B/C 样 → 车规验证 → 定点 → 正式订单 → 交付 → 稳定量产及利润。样品或道路测试只支持对应阶段，不能跨级推断收入；名义 GWh 规划也不是设备订单。
3. 材料与设备的受益方向需分开。电解质、负极、隔膜可能随技术路线替换而受益或受损；设备需有中标、预付款、交付、验收和回款。验证良率、生产节拍、外部压力、循环条件、系统成本及同期液态电池竞争，不把实验室参数当作商业优势。
4. 汽车、储能、低空、机器人等终端场景，只有真实采购、交付和可承受成本才形成近期电池需求传导。上半年累计需求增长或技术前景若没有本日新增预期差，不自动预测电池 ETF 下一开盘后三日收益。

固态技术进展只有传到候选 ETF 的订单、收入或成本变化，并留有下一开盘后的影响时，才预测三日收益区间。
