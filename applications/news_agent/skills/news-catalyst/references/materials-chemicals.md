# 化工与材料

读取条件：轮胎、维生素/氨基酸、民爆/钾肥、聚酯/涤纶/粘胶、煤化工、PEEK、培育钻石和钛合金/3D 打印。金属资源及贵金属读 [工业金属与贵金属](industrial-metals.md)。

- **化工价格**：产品报价、真实成交价、价差、销量、开工、库存及原料成本分别核查；售价上涨但成本涨得更快时利润可能下降。厂商停产须看占行业产能、修复时间和下游替代；公告提价若未落实到订单/财报，不推断利润。
- **轮胎与出海**：天然橡胶、炭黑和运费是成本，品牌、渠道、产能利用及海外认证决定传导。绿色标准/贸易限制先核实具体产品适用范围、生效时间、客户条款、合规成本和订单；仅有 ESG 表态或泛称碳关税不足以判断受益。监管范围会变化，实时模式需核对当时官方文本。
- **稀土、贵金属和小金属**：分矿权/权益产量、冶炼、磁材或加工、库存与套保。金价或稀土报价上涨和 ETF 股票篮子盈利之间有税费、成本、价格传导、政策约束与权重差异。PEEK、培育钻石、钛合金/3D 打印需分材料牌号或用途、材料/设备/终端、客户认证及实际出货。

## 主题判定卡

| 主题 | 行业专属核查 |
| --- | --- |
| Peek 产业链 | 上游单体、PEEK 树脂/改性、终端应用逐层验证；机器人或医疗“可能使用”不等于该牌号已获认证。查有效产量、纯度/良率、客户定点、单机用量和价格。候选新材料 ETF 若 PEEK 权重很低，应保持不确定。 |
| 培育钻石产业链 | 首先分首饰级与工业/电子用途；再看制备技术、品质、产量、成品价格、渠道库存和真实下游订单。工业用途技术进展不能直接推算首饰厂利润，反之亦然。 |
| 化工行业之轮胎产业链 | 原料橡胶/炭黑、轮胎厂、渠道及整车厂分开；出口认证、产地、品牌和欧洲客户采购规则会影响份额。绿色标准新闻须核对生效产品和贸易编码，不把所有“碳关税”都算轮胎直接税负；合规成本也要入净利。 |
| 化工行业之维生素、氨基酸和蛋氨酸产业链分析 | 具体品种不可合并涨价；看有效产能、寡头停复产、饲料添加需求、实际成交价和库存。供给扰动若只是报价而未进合同，或新产能很快复产，三日预期差可能有限。 |
| 化工行业之民爆、钾肥和钛矿产业链 | 民爆按许可区域、运输及现场使用约束、矿山/基建施工量和订单核查；工业炸药、现场混装、电子雷管和矿服/爆破一体化的盈利来源不同。电子雷管替代完成后的新增需求，要看存量更新、份额和产能利用率，不能重复计算政策替代。钾肥按矿源、进口合同、港口库存与农资需求；钛矿—钛白粉—钛材按矿价、酸耗/能源、颜料需求或高端钛材认证。三个赛道不能作为一个化工价格事件。 |
| 化工行业之聚酯、涤纶长丝和煤化工产业链 | 原油/PX—PTA—MEG—聚酯—涤纶长丝及终端纺织按价差分段；粘胶长丝是浆粕路线的再生纤维，不能与涤纶长丝、粘胶短纤或氨纶合并提价。分别核对实际成交价、库存、开工、终端订单和上下游价差；服饰热度只是粘胶需求线索。煤制烯烃、煤制乙二醇、尿素、甲醇/MTO、焦化和电石/PVC 的下游与价差各异；油煤价差扩大还要核实 PE/PP 等产品是否跟涨、自有/外购煤成本、装置开工及下游库存。原料上涨与成品提价对不同环节方向可相反，需核实库存收益能否持续。 |
| 钛合金3D打印产业链 | 海绵钛/粉末、打印设备、工艺服务、终端零件分开；航天或医疗用途须有材料和零件认证、良率、交付量与成本。样件展示不能推断航空批量订单。 |

材料价格、监管适用范围和公司份额均须以输入日证据核实；不以主题名称推断 ETF 净收益。

轮胎新增订单要区分整车配套与售后替换，前者可能打开车型认证，后者还依赖渠道覆盖、品牌和零售动销；新车出口增长不能等额外推海外替换收入。培育钻石首饰端看价格、库存与渠道毛利，工业端看加工规格及认证，电子/散热用途的样品不能并入珠宝销量。钛合金 3D 打印也要分粉末制备、设备和航空/医疗合格零件，终端批量认证周期与设备交付周期不同。
