# 数据、应用与金融

读取条件：数据要素/安全、AI 教育/金融/智能体、云服务、全球支付、数字货币、红利策略及金融业务。

- **数据和 AI 应用**：政策授权、数据使用权、产品上线、客户部署、收费、续费、毛利依次验证。模型能力或调用量增长不自动成为上市公司净收入；数据安全事件先区分监管处罚、整改成本、客户流失及安全供应商订单。
- **软件商业化**：把演示/免费试用、付费试点、正式签约、验收/订阅、续约扩席和现金回收分阶段。下载量、DAU 或调用量需结合留存、付费率；合同额需分 ARR/MRR、待履约订单、递延收入和已确认收入，避免重复计算。推理/云成本、渠道分成和获客费用可能抵消增长；订阅提价还需核对流失率和续约率。历史回放缺少这些当时数据时不靠软件概念给 ETF 定方向。
- **支付和数字货币**：试点、许可、商户接入、真实交易量、费率、成本、分润及清结算规模不能混同。发行或监管政策对银行、支付机构、软硬件供应商影响可能相反；跨境支付要看适用地区、合规与汇率，不能将交易额全部算作收入。
- **金融/红利**：分业务收入、信用成本、资本占用和分红可持续性；股息率是价格与分红共同结果，过去涨跌或高股息排名不是未来三日催化。宽基/金融 ETF 需要能够影响足够多成分的新增政策或盈利证据。

## 主题判定卡

| 主题 | 行业专属核查 |
| --- | --- |
| 数据安全 | 网络边界保护与数据自身的采集、存储、传输、处理、共享保护分开；政策或事故带来的新增预算要落实到产品、项目验收、续费和回款。政企项目应收与集成成本可能抵消合同增长。 |
| 数据要素 | 数据权属、合法授权、加工治理、上架交易、实际收费与现金流逐级验证；数据“入表”、交易所参股或数据量大，不等于拥有可出售的商业数据。 |
| ai教育 | 模型演示、学校试点、正式采购、学生/教师活跃、学校续费与项目回款分层；职业教育、智慧校园、K12 等客户和监管边界不同。政策规划需看地方预算与招标，不把学校入选名单当成上市公司订单。AI 教育产品的付费与利润，还要和教育 ETF 的跟踪指数、主要成分及 AI 软件权重分开核实：篮子若主要是传统教培、考试、硬件或校园集成，软件订阅增长不能直接定为该 ETF 利好。 |
| ai金融 | 将银行内部效率、风控、投顾、支付、金融 IT 供应商和金融科技 ETF 分开；核对持牌范围、银行采购/验收、收费模式、推理成本、风险损失和应收，客户数不等于利润。 |
| ai智能体 | 演示代理执行任务与真实企业流程部署、调用量、付费、续费、毛利和安全责任分层；模型能力提高可能压低软件订阅价格，也可能增加云成本。 |
| 华为鸿蒙／OpenHarmony／openEuler | 分终端 HarmonyOS、开源 OpenHarmony 行业发行版与服务器 openEuler 生态，分别核实代码/适配、商用发行版、实际装机、客户采购、应用分成及运维收入。生态会员、兼容认证、开源贡献或笼统的“华为相关收入”不能当成某系统的收入；查上市公司具体业务占比、付费客户和 ETF 成分权重。 |
| 全球支付行业产业链分析 | 分发卡、收单、清算网络、跨境结算、商户服务与托管；交易额须乘实际费率、分润并扣清算/获客/风控成本，汇兑及监管可改变净利。 |
| 数字货币产业链分析 | 区分央行数字货币、稳定币、支付通道、软硬件改造与托管；政策试点、牌照申请、正式许可、商户使用和手续费收入不能混成一条利好。核查适用司法辖区和时间。 |
| 红利策略分析 | 现金分红、自由现金流、负债及再投资需求决定分红可持续性；指数调仓或高股息回顾本身不是新增三日催化。 |

Deepseek/开源模型还应按 [算力与云](computing-cloud.md) 的硬件路径和本页的软件收入路径分别判断，不能把模型热度给两个篮子重复计收益。

监管状态与商业化规模随时间变化，须以输入日材料核实；政策方向和技术演示不能替代收费与利润。

教育软件应拆个人订阅与学校/地方财政采购：个人看付费留存和获客成本，学校看采购、交付、验收、跨学期续费和应收。金融智能体还要核实持牌主体、人工复核、错误责任与风控成本，银行内部降本不等于金融 IT 供应商新增收入。跨境支付把报文网络、资金清算、收单和汇兑服务分开；稳定币发行、储备托管、链上转账与商户收单的收入主体不同，交易额或流通量不能直接算某只 A 股 ETF 的手续费。
