# 端侧 AI 与消费电子

适用：AI 手机、眼镜、折叠屏、MR、面板、品牌供应链和端侧 SoC。把发布/预订、实际交付、退货与活跃、供应商收入分开；终端热度不能直接推算零部件 ETF 三日利润。

| 合并主题 | 需要核对的差别 |
| --- | --- |
| 端侧算力soc | 芯片、算法、操作系统、设备和应用收费分层；本地推理功能须落实到具体终端型号、SoC 单价/份额、能耗与实际出货。 |
| ai眼镜 | 轻量化、续航、显示/光学、语音或视觉交互决定使用场景；销量、退货、活跃、应用留存和真实供应商份额，比发布视频或搜索量更接近商业化。 |
| 苹果ai手机／华为手机链 | 软件功能发布、终端出货、单机用量及供应商定点逐级核实；一供、备供和泛概念不可等同。行业总量持平或下滑时，分清品牌份额转移与高端机结构升级；供应商增量取决于该品牌出货、单机价值、实际供货份额及收入占比，还须扣其他客户下滑。品牌厂商增长也可能伴随零部件年降或组装端低毛利。 |
| 叠屏手机产业链分析 | 铰链、UTG、柔性 OLED、轻量材料与贴合设备的单机增量不同；定点、良率、规模成本和出货量决定订单兑现。路线替换可使原有结构件受损。 |
| LCD面板产业链 | 尺寸结构、真实成交价、开工率、库存、玻璃/材料成本与电视需求共同决定利润；主动控产抬价若伴随销量下降，ETF 净受益未必为正。 |
| 苹果MR产业链 | 高价值 BOM 要经过售价、重量/舒适性、退货率、活跃设备与付费内容的终端需求闸门；首发热度或开发者演示不能推断大众市场及持续供应链采购。 |

新款终端若只改变功能叙述，未改变供应商订单、售价或销量预期，保持观察；原文若披露订单取消、退货或降价，重新计算各环节方向，不沿用旧的“新品利好”判断。

端侧芯片看推理能力时同时核对功耗、内存带宽、端侧模型可运行性及量产终端，单独的 TOPS 峰值不足以证明用户体验或芯片提价。AI 眼镜再拆光波导/显示、传感、结构件与整机，轻量化可能增单机价值，也可能导致部件替换。LCD 面板涨价要追到玻璃基板、偏光片和驱动器各自的订单/成本；面板厂提价不自动给全部上游同向利好。
