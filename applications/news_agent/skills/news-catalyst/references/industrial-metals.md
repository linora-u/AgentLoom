# 工业金属分环节传导

本 reference 提供金属周期的判断方法。历史回放采用证据截止前可核实的新闻与原始发布，材料中的旧案例不能替代当日事实；审核结果按精筛 Prompt 的格式保存。

1. 区分矿山资源、冶炼、加工材、贸易库存和回收。矿山看权益产量、实现售价、现金成本、资源国税费和套保；冶炼看加工费、精矿供给、电价及副产品；加工材看加工价差、销量和营运资金。金属上涨不代表每个环节利润上升。
2. 库存下降、现货升水或供给扰动需要确认品种、地点、库存口径和持续性，并与事前趋势比较。单次期货上涨、美元变化或市场复盘不是新增矿山利润；商品市场若先交易，还需说明股票篮子下一开盘后的余效。
3. 资源收购或参股核查权益比例、储量品位、项目阶段、资本开支、并表和现金流。储量、名义产能或国资背书不能代替可售产量。进口成本上涨可能利好低成本资源端而伤害冶炼及下游，须给 ETF 篮子作净额判断。
4. 缺少成分权重或明确的跨企业盈利路径时，不把铜价、铝价或矿难直接映射“有色”“材料”或“矿业” ETF；可保留事实线索，弃权三日收益方向。

## 主题判定卡

| 主题 | 独有核查点 |
| --- | --- |
| 工业金属之铜产业链 | 铜精矿紧张先改变冶炼加工费，未必改善铜冶炼利润；矿山权益产量、库存、套保与加工材订单分别核实。 |
| 有色金属铝产业链 | 铝土矿/氧化铝、电解铝、铝加工分开；核对自有矿与外购矿、氧化铝采购及电价如何决定企业在成本曲线上的位置。产能指标、复产约束、库存与下游加工费也会改变净利；同样的铝价上涨，对高成本电解铝和以外购铝为原料的加工商未必同向。 |
| 有色金属稀土产业链 | 轻稀土镨钕与中重稀土的供给、配额和下游需求不同；资源/冶炼/磁材利润传导不同。把终端真实需求、产业链补库、宏观商品定价、开采/分离指标及出口许可四条驱动线分开：补库或风险偏好推高报价，不能直接写成终端订单和上市公司利润增长。出口管制须核实品种、许可证、境内外价格、出口量及库存，原料涨价可能挤压磁材厂。 |
| 小金属小金属锑,钼和钨产业链 | 三种金属分别核实矿山供给、出口许可、冶炼加工、硬质合金/钢铁或阻燃等终端用量；不能把某一金属的限供套给其他品种。出口限制还须分别核实境内外成交价、实际出口量、国内库存和企业可销售地区；外盘涨价不等于国内持矿企业实现售价同步上涨。 |
| 上.贵金属黄金产业链分析／下.贵金属黄金产业链分析 | 分金矿、冶炼、珠宝、黄金投资工具与黄金股 ETF；矿企利润看实现售价、产量、成本和套保，珠宝商同时承受库存与需求波动。金价先交易时还需下一开盘后余效。 |

所有金属品种均须重新核实当时价格、库存、产量和 ETF 篮子；历史价格或公司名单不能替代本日证据。

黄金零售还要拆原料金价、按克计价与高工费产品、门店客流、库存计价及品牌费用；金价上涨可推高名义收入，同时压制饰品克重销量。稀土磁材看氧化物价格、磁体加工费和终端电机订单，出口许可变化须分别评估资源供给与加工商原料成本。锑、钼、钨的用途、出口限制与库存各有口径，不能用“小金属齐涨”代替单品种证据。
