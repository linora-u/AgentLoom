# 消费品、造纸与工程机械

适用：宠物、休闲零食、纸品、工程机械；同属需求观察，但客群、渠道、库存与成本不同，按相应行读取。

| 主题 | 需要核对的差别 |
| --- | --- |
| 宠物经济 | 宠物食品、医疗、用品、渠道及出口代工分开；品牌复购、终端动销、渠道库存、获客费用和原料成本决定利润，线上 GMV 不等于自有品牌净利。 |
| 休闲零食产业链 | 量贩店、直营/经销、品牌零食与代工分开；门店扩张后仍要看同店销售、折扣、退货、租金、库存和现金回款。 |
| 轻工业之造纸产业链 | 木浆/废纸、文化纸、包装纸与下游包装分开；纸价、浆价、开工、库存和真实包装需求同看。控产造成报价上涨，不等于销量或利润改善。 |
| 工程机械设备产业链 | 国内基建开工、存量设备更新、海外矿业投资、经销商库存和后市场服务是不同订单来源；月度台数需对照型号价值、出口、毛利与回款。 |

平台报告中的搜索/预订或行业累计销售是线索；预测下一交易日开盘后的 ETF 收益，还要看到新披露的边际需求、可受益的上市主体和未被价格消化的部分。旅游、酒、家电等其他候选 ETF 见 [其他场景](other-etfs.md)。
