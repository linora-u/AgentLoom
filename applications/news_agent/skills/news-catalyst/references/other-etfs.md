# 其余候选 ETF 场景

此页补足候选池中没有独立产业专题的篮子。先按 [首次披露](disclosure.md) 找到新增事实，再按 [ETF 净暴露](etf-exposure.md) 检查成分、权重和抵消项。它们是分析路径，不是新闻或收益结论。

| 候选主题 | 新闻到 ETF 的专属核查 |
| --- | --- |
| 消费、食品饮料和酒 | 品牌提价、批发价、终端成交价、销量、渠道库存与回款分开；餐饮和零售复苏也要扣折扣、原料及租金。节庆备货、研报渠道调研或单一品牌新品，不自动传到整个消费 ETF。 |
| 家电 | 分空调、白电、厨电和小家电；订单、安装、以旧换新补贴实际核销及经销商库存不同。出口增量需扣汇率、关税、海运、原材料和海外渠道成本。地产销售改善到家电交付有时滞。 |
| 养老 | 分养老服务、医疗护理、器械、保险与老年消费；政策规划要落到支付方、床位/服务利用率、定价、正式采购及公司利润。人口趋势本身不是三日催化。 |
| 旅游、酒店和景区 | 搜索、预订、支付、实际客流、客单价和上市企业利润逐级核实；天气、免费票、营销补贴和假期基数会改变净利。节假日同比数据若已公开，不重复视为新事实。 |
| 交运、航空、物流 | 客运看票价、客座率、航油和汇率；货运看运价、有效运力、吞吐、燃油与合同期限；物流看件量、单票收入与履约成本。运输量与利润不必同向，航油涨价可利空航空而利好油气。 |
| 房地产、基建与建材 | 政策表态、正式额度、执行细则、融资落地、项目开工、成交和回款分阶段。开发商净资产和销售回款、施工企业新签与毛利、建材真实发货与价格/能源成本分开；土地成交不等于利润确认。 |
| 农业、粮食与养殖 | 天气、疫病、产量、库存、收购价、饲料成本与销售价格分开。粮价上涨可能利好种植、伤害饲料或养殖；猪禽价格还要看出栏体重、成本和产能去化。局部扰动先核实覆盖范围、持续时间及 ETF 成分。 |
| 石油、天然气与煤炭 | 原油/天然气/煤价变化，对开采、油服、炼化、发电、运输的方向可相反。分资源权益产量、长协与现货比例、库存、税费和套保；短暂报价或期货波动不能代替可实现利润。海峡通行、出口量或谈判进展要与最近**同口径**状态比较，不能反复拿战前水平制造新冲击；协议框架、签署与实际复航分开。若全球商品市场已在 A 股下一开盘前交易该变化，须另有 ETF 净受益和开盘后三日余效的依据，不能只写“供给风险持续”。 |
| 钢铁、船舶与工业母机 | 钢铁看成材价格、铁矿/焦煤成本、产量限制及库存；船舶看新签、船价、交付周期、钢价和汇率；工业母机看设备更新、正式订单、数控系统/核心件国产化、验收及现金回款。大额意向订单不能直接计入当期盈利。 |
| 环保与碳中和 | 排放标准、覆盖行业、实施日期、核查处罚、地方预算、正式招标及回款逐级验证。环保设备订单与运营收费机制不同；碳价上涨可能提高减排资产价值，同时增加高排放成分成本。 |
| 游戏、传媒与影视 | 版号/发行许可、上线/定档、活跃用户、付费、分账、宣发与开发成本分开；内容热度和票房总额要扣渠道分成与制作费用。单款产品或单片的影响还需看 ETF 持仓权重。 |
| 券商、银行与保险 | 成交活跃度、融资融券、投行业务和自营交易对券商利润路径不同；银行看息差、信贷需求、不良、拨备；保险看新单价值、投资收益和负债成本。已发生行情推动的券商自营收入或单个分项增速，不等于未被市场计价的行业净利润惊喜；核实同口径净利及 ETF 篮子影响。政策利好一环不代表金融篮子同向。 |
| 宽基、红利与跨境 | 宽基须有足以改变多数成分预期的事实，单一行业消息通常被低权重稀释；红利须看现金流和分红可持续性。跨境 ETF 先查跟踪市场、汇率及交易时区；境外市场已经交易的部分，不算作 A 股下一开盘后的新增收益。 |

多个主题同时受同一事件影响时，分别写清收入与成本方向，并按候选 ETF 的实际成分决定是否给方向；缺成分或缺新事实就保持不确定。
