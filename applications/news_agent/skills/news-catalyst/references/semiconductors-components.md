# 半导体、存储与电子材料

适用：晶圆厂设备、存储、功率器件、PCB/载板、铜箔、MLCC 等。终端需求与晶圆厂资本开支可以错位；看具体产品代际、客户认证、可交付产量、重复订单及毛利，不用“国产替代”“AI 芯片”统称全链条。

全球半导体营收或价格指数创新高时，先拆增长由存储、逻辑芯片、代工、设备还是其他环节贡献，再核对候选 A 股 ETF 的实际成分与权重。境外存储厂的提价和全球行业总量不能直接推算境内设备、设计或功率器件公司的新增利润；还要核实统计首次披露时间与开盘后尚未消化的预期差。

| 合并主题 | 需要核对的差别 |

| 长鑫长存产业链／存储芯片产业链 | 扩产链的洁净室、设备、材料，与涨价链的颗粒、模组和终端分开；DRAM/NAND、HBM、显存、企业 SSD 主控和成熟利基品类不能互替。核对合约价、位元出货、库存、客户认证及模组持有颗粒的成本。 |
| PCB产业链／PCB行业产业链分析260612 | 普通服务器板、AI 加速器板、高速交换板、ABF/FC-BGA 封装基板、车用板的材料、层数、良率和认证周期不同。按板级位置、客户与收入占比核实，不能把普通 PCB 当先进封装纯受益。 |
| ai铜箔和电子分布（高速铜箔、电子布与 PCB 材料） | 高速电子铜箔与锂电铜箔分开；核实 RTF/VLP/HVLP 等低轮廓产品的粗糙度、厚度、低损耗能力和具体板级用途。电子布/玻纤布另看 Dk、Df、CTE、纱线细度及 Low-Dk/石英纤维布的客户认证。普通电子布产能、名义高端铜箔产能和送样都不能当作高代际产品批量交付；还要看良率、实际订单、收入占比和新增利润相对原有利润的弹性。铜价上涨不等于高端材料溢价兑现。MPO/MTP 光互连走 [AI 光通信](ai-optics.md)。 |

| 射频前端与被动元件 | 电阻、电容、电感与滤波器、射频开关、功放、天线等有源/射频器件分开，手机、卫星和服务器的规格及采购周期也不同。产品进入新机型、客户认证、单机用量与 ASP 比“射频国产替代”更能说明增量；元件涨价须扣原料和良率。 |

高端 MLCC 再拆介质粉体、内电极镍粉、流延/烧结设备与成品。消费级缺货不证明服务器或车规器件提价；高端客户认证通常跨多个批次，按新闻当时的认证、供货和价格证据判断，不能把计划扩产记作有效供给。封装基板还要区分 ABF、玻璃或陶瓷等不同路线的试验、认证与量产，路线预测不是既定替代。

原料、器件、模组与终端的受益方向可能相反。ETF 判断须核实成分权重和利润所在环节；高端技术名词、产能规划、样机、送样仅是待验证里程碑。
