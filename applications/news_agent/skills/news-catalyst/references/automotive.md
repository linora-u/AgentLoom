# 汽车、智能驾驶与两轮车

适用：整车销量、智能驾驶、车路云、汽车零部件和两轮车出海。先看事件改变了车型/功能/地区覆盖还是实际订单，再区分整车、Tier 1、零部件与运营商的收入和成本。

| 合并主题 | 需要核对的差别 |
| --- | --- |
| 全球智能驾驶产业链分析 | 辅助驾驶、限定区域路权、无人出租车和无人物流车的许可、责任及付费模式不同；看有效车队、收费里程与使用率、接管/事故率、车辆折旧、远程运营/保险/充电等成本，以及乘客或物流客户实付。自营车队省下驾驶员成本，与向车厂销售算力、传感器或软件是不同利润路径；不把测试里程当营业收入。 |
| 车路云一体化产业链 | 路侧感知/通信、云控、车端改造与运营服务分层；试点名单之后仍需预算、正式招标、中标、验收、运维与跨城复制。 |
| 华为汽车产业链 | 品牌、整车厂、智驾软硬件和零部件供应商的利润归属不同；车型发布、可退订订单、批发、零售和交付各有口径，供应商还需定点、单车价值、年降和毛利。 |
| 汽车零部件产业链分析（上篇）／汽车零部件产业链分析（下篇） | 底盘、轻量化、热管理、智能化、电驱按 BOM 和技术代际区分；送样→定点→SOP→量产交付→质保回款。订单增量若被年降、召回或原料涨价吞噬，不能推断利润同步增长。 |
| 扬帆出海之电动两轮车和摩托车产业链 | 电池/电机/整车、经销渠道、当地准入和本地化生产分开；出口装船、经销商库存、终端销售及回款不可混用。认证、关税和售后可改变利润。 |

整车销量与零部件单车价值、价格战和利润可能反向；候选 ETF 若以汽车整车为主，不以零部件新闻自动定档。

自动驾驶路线比较须分车端传感/算力、路侧设备、北斗高精定位和 ETC/通信方案。哪种方案更省建设费用属于待验证假设；只有明确的许可范围、付费主体、招标和车型装配，才能决定对应 ETF 受益。智能座舱域与智驾域控制器服务不同功能；座舱屏、语音交互增量不能直接算作刹车/转向执行器订单。
