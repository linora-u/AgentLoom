# 航天、北斗、深海与军工

适用：商业卫星、可回收火箭、导航、深海装备、军贸及战斗机/导弹。按任务链定位上市主体，先有任务/采购主体，再谈 ETF；涉密或海外供应商身份不可猜测。

| 合并主题 | 需要核对的差别 |
| --- | --- |
| SpaceX产业链／卫星互联网产业链 | 发射服务、整星、通信载荷、相控阵/射频、星间通信、信关站、终端、星座运营分开。单颗试验星只验技术；连续批量发射、正式硬件合同、可用覆盖和付费用户分别验证建设与运营。境外订单须有 A 股供应商身份、份额和交付证据。 |
| 可回收火箭产业链 | 区分技术试飞、成功回收、可靠复用、翻修周期、单位发射成本和可持续商业发射；箭体材料、发动机、测试设备的订单未必同时到来。 |
| 北斗导航产业链 | 空间段、芯片/模块、终端、系统集成与应用服务有不同采购周期；试点/国产替代先看政策范围，再看认证、订单、装机、订阅或运维。 |
| 深海科技产业链分析 | 海工、科研探测和军用声呐的资金来源与交付不同；水下换能器/传感、信号处理、通信和整机需有规格、可靠性、招标与验收。科研样机不能填作批量舰船订单。 |
| 军工军贸产业链／79.军工之战斗机和导弹产业链 | 意向、出口许可、正式合同、交付、回款与利润归属逐级验证；整机、发动机、航电、材料、弹药供应商不等权。型号定型与列装也不同，涉密细节缺失时保持不确定。 |

发射计划、军演或政策预算只是任务线索；ETF 三日判断需要明确到时点、规模、所属供应链环节和开盘后余效。多个稿件重复同一任务，不叠加新闻强度。
