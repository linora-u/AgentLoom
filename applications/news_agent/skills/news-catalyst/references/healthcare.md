# 医药与医疗

读取条件：创新药、减肥药、AI 医疗、医院、器械、辅助诊断和手术机器人。这里评估**资本市场新闻传导**，不判断诊疗效果；安全性、批准范围和支付规则以当时监管与原始披露为准。

- **药物**：靶点/临床前、临床试验各阶段、主要终点、审批受理、获批、医保/商业支付、实际销售不能跨级推断。授权交易拆首付款、里程碑、权益比例、适应症及地区；总潜在金额不是已收现金。减肥药需分剂型、适应症、疗效与不良反应、产能、支付和竞品；不能用赛道热度替代公司收入。
- **AI 医疗**：数据、模型、医生工作流、医疗器械审批、医院部署和付费是六个不同环节。模型接入或演示仅说明技术可行性；临床使用、采购合同、医院回款、订阅与毛利才构成商业化。AI 制药发现候选分子到临床/授权仍有显著距离。
- **医院和器械**：客流、客单价、支付来源、耗材复购、医保控费、应收及回款须分开；单院开设或宣传合作不等于连锁 ETF 受益。手术机器人分别看装机和手术量；器械获批不等于医院采购。

## 主题判定卡

| 主题 | 行业专属核查 |
| --- | --- |
| ai医疗 | 数据权属与脱敏、医院 HIS/EMR 等入口、器械软件审批、医生工作流、收费与回款分层；模型接入不是临床部署。远程问诊流量要经过处方、药房、复诊或支付环节才能产生利润。 |
| 创新药产业链 | 管线临床阶段、主要终点、审评、上市许可、医保支付与销售逐级验证；对外授权拆首付款、里程碑、地域和权益归属，不把潜在总交易额作已实现收入。 |
| 减肥药产业链 | 分分子/作用机制、适应症、给药方式、临床效果与安全性、产能、支付和竞品；仿制/生物类似药或原料供应商须有获批与销售证据，不能因全球赛道增长推算 A 股 ETF 利润。 |
| 民营医院之康复、辅助生殖、口腔和中医医院产业链 | 四类业务的准入、支付与复购不同：康复看床位利用和康复周期；辅助生殖看牌照、周期量和成功率口径；口腔看获客、客单与材料成本；中医看院外服务、支付与标准化。均核对单院成熟度和连锁复制成本。 |
| 民营医院之肿瘤、美容和眼科医院产业链 | 肿瘤看学科/设备/医保与支付能力；医美看获客、合规与复购；眼科看手术量、医生资源、器械耗材与定价。新院开张或高客流不足以证明净利润，须核查折旧、医生费用、营销成本和现金流。 |

以当时的临床披露、监管状态和支付路径核实具体事件；不把行业前景或医学推测写成已获批收入。
