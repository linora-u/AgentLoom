# 电力与新能源

读取条件：国内电网、电力设备出海、发电、可控核聚变、钙钛矿、制氢、储氢/加氢。固态电池单读 [固态电池](solid-battery.md)。

- **电网**：主网、配网、特高压和二次设备的预算、采购方与交付周期不同。用正式招标/中标金额、分包、交付、验收和回款区分规划或政策目标；预算发布并不保证每家候选 ETF 成分公司中标。出口订单还要看认证、本地化、关税和汇率。
- **电力**：区分发电量、上网电价、燃料成本、辅助服务及资本开支；高电价对发电端与用电大户的作用可能相反。容量规划、核准、开工、并网、利用小时、实际结算是不同阶段。
- **钙钛矿/核聚变**：实验效率、稳定性、组件认证、示范项目、商业订单与可复制量产逐级验证；核聚变装置实验、供应商中标与可售电力之间时间跨度很长。单次技术突破通常不足以预测三日行业 ETF 盈利。
- **氢能**：制氢、储运、加氢站、终端用氢分别核实电价/原料、设备利用率、运输成本、实际用量及补贴到账。名义产能、签约站点数或技术示范不等于持续现金流。

## 主题判定卡

| 主题 | 行业专属核查 |
| --- | --- |
| 电力行业产业链 | 水电看来水与折旧；火电看煤价、电价、利用小时与容量补偿；核电看许可、投运和资本成本；风光看消纳、上网价、补贴及融资。AI 用电预测只有落实到长期购电协议、并网容量和电源资产，才可传到电力股。 |
| 扬帆出海系列之电力设备产业链 | 海外投资计划、客户白名单/认证、招标中标、交付、收入和回款逐级验证；变压器、分接开关、电表与配电设备的价值量不同，还要看当地认证、产地、关税、汇率及售后。 |
| 国内电网设备产业链 | 主网/配网/特高压/二次设备分开；监管预算、项目批复、招标、具体中标和验收有时间差。设备企业可能垫资，新增订单需对照交付周期、应收和现金流。 |
| 行业专题：可控核聚变产业链分析 | 聚变产额、靶增益、等离子体持续时间、Q 值和全厂净发电不是同一指标；核对实验条件及能否重复，不能把科学纪录写成商业发电。托卡马克、仿星器与惯性约束的设备需求不同，低温超导与高温超导材料也不能互作供货证据。点火纪录、工程采购包、设备验收和商业电站相距很远；分超导磁体、真空室、偏滤器、加热电源、冷却和燃料循环。近期 ETF 受益须有明确采购合同。 |
| 钙钛矿产业链 | 实验室电池效率、组件面积、长期稳定性、认证、量产良率及实际订单分开；设备/材料订单需与真实产线投建绑定，名义 GW 规划或单片效率不能推导组件利润。 |
| 储氢和加氢产业链 | 高压气态、液氢、固态/载体等路线的设备价值和运输成本不同；加氢站看车辆保有、日加注量、利用率、零售价格、安全审批与回款。 |
| 制氢产业链 | 绿氢/电解水与化石原料制氢分别核实电价、设备效率、产能利用、碳成本和长协购买方；电解槽出货与制氢项目利润分属不同公司。 |

新增数据中心用电或绿电比例目标，先核实约束对象、生效日期、当地可并网容量、购电合同与结算价格，再判断发电、电网设备和高耗电企业各自方向。容量电价、辅助服务和电能量交易是不同收入项，不用政策目标百分比直接乘上市公司发电量。海外变压器缺货或涨价须区分本地认证、有效交期、铜价与售后成本，不能只按报价给出口利润定档。
