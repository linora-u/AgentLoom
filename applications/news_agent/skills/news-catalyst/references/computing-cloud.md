# 算力、云服务与 AI 基础设施

适用：模型、TPU/ASIC、国产算力、服务器、云与 IDC、液冷、交换机。先问模型或应用的真实需求是否改变，再沿资本开支→采购→交付→使用率→付费与现金流传导；AI 相关不等于同一家公司收入。

| 合并主题 | 需要核对的差别 |
| --- | --- |
| AI 通胀 | 高端存储、互连、PCB 材料、电源和散热的名义产能，需扣良率、客户认证、实际开工后才是可交付供给。上游涨价可能同时压低云厂商或组装端利润，核实成交价、成本转嫁和合同期限。 |
| 谷歌tpu／asic集成电路 | TPU/定制 ASIC 与通用 GPU 可分工；客户自研芯片需求不自动转成外部芯片设计商收入。核对芯片设计权、代工/先进封装份额、网络架构、采购数量、软件生态及云应用变现。 |
| Deepseek／国产算力／华为昇腾和鲲鹏算力产业链 | 开源模型接入、软硬件适配、生态伙伴、智算中心中标、整机交付、利用率与回款分阶段。区分芯片、整机、系统集成、租赁和应用收入；“AI 相关收入”不能直接充作某一算力平台收入。 |
| ai云／全球算力 | 云厂商预算、服务器和网络采购、IDC 上架率、算力租金/利用率、折旧、电价、现金流分别验证。扩建机房或签算力意向协议不等于可持续的高毛利云服务。交换机与路由器、光模块用途不同，速率升级须见采购和交付。 |
| 全球算力服务（服务器整机及服务） | 分海外 AI 加速器/GPU、服务器整机与 ODM、国内运营商/政企采购、国产芯片、HBM/封装、PCB/电源/液冷/网络配套及云运营。整机厂要核实 AI 服务器收入占比、正式订单、客户集中、交付和毛利；运营商订单看招标份额及回款；云服务还要扣折旧、电费和利用率。不能把海外芯片销售额、服务器合同额与国内云租赁收入当成同一层收益，也不能把 ETF 中各层权重简单相加。 |
| ai液冷 | 先确认机柜实际功率密度和冷板、CDU、浸没等选定方案，再看客户平台、单机价值、可靠性、交付及运维；液冷渗透率预测或普通空调业务不能代替高功率机柜定点。 |

算力利用率上升可提高服务收入，却也可能推高电力、设备折旧和融资成本。境外资本开支已经在其股票市场交易时，不把隔夜涨幅重复算为 A 股 ETF 下次开盘后的三日收益。光通信部件见 [AI 光通信](ai-optics.md)；端侧 SoC 见 [消费电子](consumer-electronics.md)。

TPU/ASIC 相关新闻还要拆芯片、封装、服务器、光交换 OCS、光模块及软件服务的实际采购架构；OCS 改变网络连接方式不等于取消光模块。云平台广告代理、渠道销售或泛生态合作通常是弱一阶传导，须见独立合同与净利润。算力租赁订单看已上架算力、实际使用小时、单价和回款，避免将“机柜建成”与“GPU 满载付费”混写。
