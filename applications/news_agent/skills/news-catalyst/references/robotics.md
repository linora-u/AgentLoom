# 机器人与核心部件

适用：人形、工业、机器狗和手术机器人。先定位本日新增的可验证里程碑，再看候选 ETF 对供应商的净暴露；品牌发布会、视频和供应链身份只说明关注度。

| 合并主题 | 需要核对的差别 |
| --- | --- |
| 机器人／华为机器人／全球机器人产业链／特斯拉机器人 | 技术展示→任务成功率→连续运行可靠性→成本可接受→客户场景复制→正式采购→整机量产→供应商收入。不同品牌的路线、BOM、采购方与上市供应商份额不可互借；阶段只升到有原文证据的节点。 |
| 本体与零部件 | 分本体、执行器、丝杠、减速器、电机、力/触觉传感、灵巧手、精密设备及通用结构件。核实单机价值、实际装配数量、客户认证、良率和收入占比；线性/旋转执行路线切换可能令环节方向相反。 |
| 手术机器人 | 主机装机、获准适应症、医院采购、真实手术量、耗材复购与维护收入逐级验证；可用技术不等于医院支付或器械公司利润。 |

订单数量是整机还是样件、是否取消或递延、供应商是正式定点还是备选，决定能否传到 ETF。量产规划若缺良率、单位成本和可复制应用场景，不按整条产业链同步获利处理。机器人材料 PEEK 的材料级与客户认证，另见 [化工与材料](materials-chemicals.md)。
