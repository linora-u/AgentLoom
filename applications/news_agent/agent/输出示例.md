# 精筛输出示例

只输出一份 reviews，程序从其中提取方向决定。无关或未核实的消息也保留放弃记录。

```json
{"reviews":[{"event_id":"E1","etf_code":"510300.SH","record_numbers":[1],"summary":"新增监管约束","decision":"利空","reason":"核实新增执行条款并判断其对主要资产的持续影响","sources":[{"url":"https://example.org/original","published_at":"2025-07-31T18:00:00+08:00","version_available_at":"2025-07-31T18:00:00+08:00","excerpt":"决定性的原文条款"}]},{"event_id":null,"etf_code":null,"record_numbers":[2],"summary":"天气预报","decision":"放弃","reason":"与候选 ETF 无明确关联","sources":[]}]}
```

示例只说明格式，网址和事实不是本日证据。
